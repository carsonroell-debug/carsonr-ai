# Carson Roell - Personal Portfolio

This is my personal portfolio website, separate from the Big Flight Deals project.

## Deployment

This folder contains a static portfolio site ready for Vercel deployment.

### Deploy as Separate Project

When deploying to Vercel:
1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Import the repository: `carsonroell-debug/BFD-scout`
4. **Important**: Set "Root Directory" to `portfolio`
5. Click "Deploy"

Or use Vercel CLI:
```bash
cd portfolio
vercel --cwd portfolio
```

## Files

- `index.html` - Main portfolio page
- `styles.css` - All styles
- `script.js` - JavaScript functionality
- `Carson_Roell_Resume.pdf` - Resume
- `assets/` - Images and assets
