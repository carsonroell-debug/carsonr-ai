# Assets Directory

Place your images here:

- `bigflightdeals.png` - Image for the Big Flight Deals project card (recommended: 800x600px or similar aspect ratio)
- `og_image.png` - Open Graph image for social media sharing (recommended: 1200x630px)
- `favicon.svg` - Favicon for the site

All paths in the HTML reference `./assets/` which will work when uploaded to your hosting provider.
